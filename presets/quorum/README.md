# Quorum sample project

This is the optional starter film and 14-chapter narration script for
[Aivy Quorum](https://github.com/jmgomezl/aivy-parametric-pool).
Use **New project** in Take Studio for another video and script.

The silent 3:59 visual edit and timeline were copied without modification from
Quorum revision `12398c62a087fd1d4b8c066be52c29e069112662` on September 11, 2026.
[Original sources and credits](https://github.com/jmgomezl/aivy-parametric-pool/blob/12398c62a087fd1d4b8c066be52c29e069112662/docs/demo-video/SOURCES.md)
include the origin of the earthquake imagery and captured product screens.
The film is an example asset, not a runtime or financial integration.

`visual.mp4` SHA-256:
`77cac975ab709e6b07489951e292ebc2eb858335caa756e9a40ebddaeae37287`

Keep `quorum-september-2026` as the default project ID and the IndexedDB database
`aivy-take-studio` at version 1 to preserve existing studio recordings. Changing
where the code is deployed does not require changing those identifiers.

The September 11 sample refresh adds Quorum's approved logo and clearer HAK
plugin contribution credits. Only chapters **8 and 13** have revised narration;
all 14 chapter times and the original transaction footage are retained.

`update.json` records the exact old and new sample wording. On startup the studio
updates only matching, unedited text in the original bundled project. Custom
wording, saved takes, selections, settings and timestamps are preserved. Projects
with uploaded videos or changed timing are excluded. Existing recordings are
never replaced: review chapters 8 and 13 and record another take if needed.
